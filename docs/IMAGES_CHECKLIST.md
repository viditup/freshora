# Freshora - image checklist (Part 3B)

Drop photos in these folders (white background, square, ~600x600 or larger, .jpg/.png/.webp). Free-licence sources: Pexels, Unsplash, Pixabay.

After adding files: set `PUBLIC_BASE_URL` in `backend/.env` to the address your phone uses (e.g. `http://192.168.1.5:8000`), then run `python -m seed.seed_data` again. `python -m seed.list_images` shows what is still missing. Anything missing keeps the green placeholder, the app does not break.

Extra gallery photos for Product Details: `<slug>-2.jpg`, `<slug>-3.jpg` ... (up to 5). Good ones to do first: tomato, fresh-apples, bananas, full-cream-milk.
